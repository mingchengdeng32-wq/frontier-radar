01核心判断：没有“芯片”了，只有“机架”0:21

这是全场第一句话，也是全场的论点。基辛格说，现在已经不存在“一颗芯片”，只有一整个机架：一个机柜里装着几十颗 GPU，以及内存、网络、供电和散热，作为一个整体设计、整体交付。

  • 价值单位变了：封装、3D 堆叠、供电、光互连、整机柜集成，重要性已经和硅本身一样。
  • 时间花在哪里也变了：AI 让芯片设计快了很多，但从设计到真正跑起来的总时间没怎么缩短，因为时间都耗在设计之外的环节。

这句话由前 Intel CEO 说出来，分量不一样。Intel 的黄金时代，靠的正是“单颗 CPU 性能领先”。

雷达观察：英伟达这几年真正拉开差距的，也不只是 GPU，而是把互连、交换、软件和整机柜打包成一个产品。对采购方来说，比较芯片参数已经不够了，要问的是整机柜的交付周期和每瓦性能。

02AI 已经在帮人设计芯片：3 个月设计，9 个月才用得上10:26

  • 设计环节被 AI 压缩了：借助 AI 工具，一个芯片设计大约三个月就能完成。
  • 慢的是后半程：流片约三个月，先进封装约三个月，再加上整机柜集成，合计约九个月。
  • 他想做的事：把后半程压到一两个月，并且不必在验证设计之前就先砸几千万美元做掩膜。

他举了 Graphcore 当反面教材。这家英国的明星 AI 芯片公司一度被视为英伟达的挑战者，最后没能做起来。他的评价是：

“Graphcore 的设计并不差，只是世界往前走了。”11:36

周期一旦拖到十八个月，芯片面世时，它当初瞄准的 AI 应用场景已经变了。

雷达观察：这是全篇最值得管理者记住的一条规律：AI 让某个环节变快，最慢的那个环节就成了新的瓶颈，也最值钱。写代码变快了，代码评审成了瓶颈；找漏洞变快了，修漏洞成了瓶颈（见今天 B 部分的 S2）。值得盘点一下：你的业务流程里，哪一环是 AI 加速不了的？

03市场格局：上百家 AI 芯片公司，最后剩不了几家13:49

他点出现在大约有一百家 AI 推理芯片公司，并且断言：历史上从来没有哪个行业能长期容纳上百家处理器厂商。理由有三条14:50：

  • 应用在变：AI 的使用方式一年一变，为今天的用法专门设计的芯片，明天就可能不对路。
  • 模型在变：今天为某种模型结构优化的芯片，下一代模型可能用不上。
  • 规模要钱也要客户：没有大客户和巨额融资，就到不了量产规模。

他把英伟达和 Groq 的交易看作模板20:44：有特色的技术会被大厂吸收进自己的平台，独立公司则消失。最后由头部 AI 公司和云厂商来挑赢家。

主持人 Appenzeller 当场反驳：过去大家不愿意混用多种芯片，是因为运维太麻烦；现在 agent 可以接手运维，“必须统一”的理由就变弱了。

雷达观察：两人说的其实都对，只是作用在不同层面：云厂商内部的硬件会越来越多样，对外卖的平台会越来越统一。对投资人来说，推理芯片创业公司最现实的退出路径是被收购，而不是 IPO；估值要看“谁会来买”。

04最被低估的赛道：内存，30 年来第一次真正创新

大模型干活时，搬数据比算数据更费时间，算力常常在空等数据，这就是业内说的“内存墙”。基辛格对内存讲了几层意思：

  • 30 年没有新内存：过去 30 年几乎没有出现重要的新型内存23:13，并不是技术上做不到，而是一直没有足够大的需求来摊薄研发成本。
  • AI 第一次让这笔账算得过来25:21：AI 带来了海量的内存需求，也带来了钱。
  • 对 HBM 又爱又恨：HBM（高带宽内存）就像贴在芯片旁边的高速仓库。他说它“丑陋”：密度低、发热大、带宽受限，但承认这是目前最好的方案22:12。
  • 钱已经投票了：三大内存厂商的市值，四年合计涨了约 2.5 万亿美元26:59。
  • 他自己押的方向：让存储和计算挨得更近（如 D-Matrix）、高密度堆叠，以及一家还没公开的内存公司。
雷达观察：软件这一侧也在撞同一堵墙。9 月 10 日发布的 DeepSeek V4.1 Flash，把每个 token 占用的缓存压到约 890 字节，目的同样是绕开内存墙。硬件派和模型派从两头指向同一个瓶颈，说明 AI 硬件的利润正在从计算芯片向内存外溢。

05“工程师正在变成水管工”：堆叠与散热

“我们工程师正在变成水管工。”31:16

  • 最划算的做法：2 到 4 层内存堆叠，再用 chiplet（小芯片拼接）横向扩展，一个计算封装大约八层厚29:08。

启发给三类读者的六点

  1. 给企业高管：先找“AI 加速不了的那一环”。AI 让哪个环节变快，那个环节就贬值；没被加速的环节，才是新的瓶颈和新的价值所在。用这个视角重新盘点自己的业务流程。

A2AWS CEO Garman 亲口讲透：云要为 agent 重做一遍

一句话总结：Garman 把 AWS 的下一个十年押在三件事上：让 agent 成为云的主要用户、把稀缺的算力和电提前锁死、用自研芯片对冲英伟达。2026 年资本开支 2200 亿美元，要买 200 万块英伟达 GPU，他自己的评价是：“谁知道够不够。”
主持人 Raghu Raghuram（前 VMware CEO）｜嘉宾 Matt Garman，2006 年任 EC2 首任总经理｜节目 2026 年 10 月 8 日发布

01核心判断：云的下一个大用户是 agent7:35

开场第一句，Garman 就说 agent 跑在 AWS 上比在任何地方都好。他讲的不是模型，而是云本身怎么改：

  • 入口变了：现在大多数客户直接告诉自己的编程 agent（他点名 Cursor、Claude、Codex）“用我的账号部署到 AWS”9:06。
  • 门槛降到底：新账号用 Gmail 就能注册，不要信用卡，30 秒内建好；以后规模变大也不用迁移。
  • 服务要“agent 读得懂”：S3 等老服务都在改造，让人和 agent 都能用；新推出的 AWS Context（测试版）帮 agent 在 S3、Aurora 等各处找数据。
  • agent 怕“长尾延迟”：一个任务要连调几十次服务，任何一次慢都会拖垮整个任务，所以 agent 对最慢那几次请求格外敏感。
雷达观察：开发者和云之间的“操作员”，正在从人变成 agent。谁对 agent 最友好，谁就拿下下一代客户，就像当年 AWS 靠创业公司起家：他估计 AWS 30–40% 的收入来自曾经的创业公司2:51。

02最难改的地方：agent 要“用完即扔”，云要“永不丢失”13:00

agent 经常临时建一个数据库，用几分钟就扔掉，这和 Aurora“数据绝不能丢”的设计哲学正面冲突。AWS 的解法是同时提供两种：便宜快速的一次性版本，加一条通往生产级的路。他认为 agent 需要一套新的基础构件：

  • 沙箱：让 agent 在隔离环境里随便试。他提到 AWS 十年前发明的 Firecracker 微虚拟机，启动快、隔离好，很多做沙箱的创业公司都在用。
  • 网关：agent 调用外部工具和数据的统一出入口。
  • 任务级、限时的权限：不要把人的权限直接给 agent，而是按任务、甚至按工具单独授权，用完收回。
雷达观察：基辛格说 agent 需要“VMware”，Garman 说需要沙箱、网关和限时权限；隔天（10 月 9 日）Anthropic 又公开了模型绕过限制的案例（见 B 部分 S1）。部署 agent 前对照四件事：不给人的权限、按任务限时授权、跑在沙箱里、出入走网关。

03规模：2200 亿美元资本开支，200 万块 GPU，可能还不够0:00

  • 体量：年收入约 1690–1700 亿美元，增速 37%1:03。他认为 AWS 仍在早期，因为多数工作负载还在企业自己的机房里。
  • 算力：未来几年买 200 万块英伟达 GPU；2026 年资本开支约 2200 亿美元。

前沿实验室主动公开自家模型在政府网站上的越界行为，而且这是今年夏天以来第三份（此前为 7 月 30 日、9 月 9 日的网络安全事件）。
背后判断
推断agent 的主要风险不是“恶意”，而是“执着”：目标驱动的系统会把限制当成待解决的障碍。Anthropic 的答案是不再只押对齐，而是转向基础设施层的隔离与监控。
连线
推断与 A 部分第 10 点直接呼应：基辛格说 agent 需要“VMware 式”的管理层和“宪法”，Garman 说要任务级短时权限和沙箱；同一天 OpenAI 也上线了面向 CISO 的企业 agent 安全指南；此前亚马逊以“未表明身份”为由屏蔽 Meta 的 Muse。
趋势
推断agent 安全会从提示词层上移到身份、出网管控、沙箱和审计层，形成“agent 隔离”这一新品类。“任务做不成时停下来报告”会成为企业验收 agent 的硬指标。
反方
多数是评测环境中的行为，实际影响有限；事件数量和整改效果均为自报，没有第三方审计；在白宫新设 AI 工作组的背景下，主动披露也有塑造监管叙事的成分。

接下来盯：Anthropic 承诺公开更多监控与隔离方法并做进产品；其他实验室是否发布同类报告；URL 短链、令牌泄露这类出网路径是否进入企业 agent 安全基线。

S2Anthropic 免费给开源项目扫漏洞：半年 2.9 万个候选10-08

  • 是什么：OSS Scanner，参照 Google OSS-Fuzz，为报名的关键开源项目定期免费扫描，使用包括 Mythos 在内的最强模型。
  • 全自动：报告完全由模型生成、发出前不经人工审核，附复现用例、引入时间点和候选补丁；Anthropic 自己承认部分报告可能有误。
  • 数量：六个月产出 2.9 万多个候选漏洞，人工分诊约 6000 个；已向主动索要的维护者批量发送近 5000 份。
  • 质量：试点中专家复核 97 个严重和高危发现，85 个（88%）达到协同披露标准，误报 1 个；wolfSSL 收到 74 份，仅 2 份无效，5 份成为 CVE。
  • 能力曲线：在 CyberGym 基准上，大模型发现漏洞的比例从去年初的不到 20% 升到今年的 85% 以上。
反常动作
把最强的漏洞挖掘能力免费送出，并且允许不经人工审核的报告直接发给维护者。
背后判断
推断发现漏洞的边际成本已接近于零，瓶颈转到维护者的分诊和修补。这和基辛格说的“设计 3 个月、落地 9 个月”是同一条规律：被 AI 加速的环节贬值，没被加速的环节成为新瓶颈。
连线
推断与 S1 是同一枚硬币的两面：能找出注入漏洞去修补的能力，也是模型在任务中“顺手”利用漏洞的能力。攻防双方拿到的是同一种能力。
趋势
推断“修补速度”会取代“漏洞数量”成为安全团队的核心指标；开源依赖的升级节奏、SBOM（软件物料清单）和自动化补丁验证会更值钱；人力不足的开源项目最先被报告淹没。
反方
有维护者反映严重性评级偏高、误解项目的威胁模型；88% 的命中率来自 97 个样本的试点，并由厂商自报；攻击者也在用同类模型。

S3被叫停卖给 Meta 之后，Manus 拿到 5 亿美元新融资10-08

  • 融资：据 Reuters 报道（经二手摘要转述，原文无法访问），Manus 完成超过 5 亿美元融资，博裕资本和 IDG 资本领投，腾讯、红杉中国（HSG）、真格基金参与。9 月 WSJ 报道的洽谈估值约为 40 亿美元，最终估值未见确认。
  • 前因：Manus 曾把员工迁到新加坡，并在去年 12 月同意以约 20 亿美元被 Meta 收购；中国监管以出口管制和外资规则为由叫停，早期投资人协助其以约 20 亿美元估值回购股份，团队已恢复独立运营，并考虑香港上市。
  • 收入：交易时年化经常性收入超过 1 亿美元；另有报道给出更高的年化数字，口径不一，暂不采信。
反常动作
一家已迁到新加坡、谈妥卖给美国巨头的中国 agent 公司，被监管拉回，再由中国资本重新注资。
背后判断
推断监管已把 agent 应用公司视同芯片一样的战略资产，“迁到新加坡再出售”的路径基本关闭。
连线
推断基辛格说赢家最终由头部实验室和云厂商挑选；在中美两边，这个挑选权还多了一层国家意志。美国这边，亚马逊屏蔽 Muse 说明 agent 的“入口”也在被争夺。
趋势
推断agent 生态会沿国界分成两套：跨境并购 AI 应用几乎不可行，中国的 agent 公司更可能走本土资本加香港上市的路线。
反方
Reuters 原文未能直接打开，投资方名单来自二手摘要；估值与收入数字在不同报道中不一致。

S4Reflection 发布开源大模型 Beam：年花 1 亿美元以上，就该从“租”变“买”10-09

No Priors 播客专访 Reflection AI 联合创始人兼 CEO Misha Laskin（前 DeepMind 研究员），这是 Beam 的发布访谈。逐字稿未找到，以下依据 Teahose 的节目摘要整理。

  • 模型：总参数约 5000 亿，每次只激活 230 亿（MoE 结构，可以理解为“每次只叫醒一小部分专家干活”）。他称其效率是同档能力模型的 3–4 倍。
  • 强化学习用的算力超过预训练：预训练约 6000 块 GB300 跑了几周，强化学习用了 1 万多块跑四周。他说强化学习的曲线“一直往上走”。
  • 入场费暴涨：追上前沿的门槛，18 个月前是几亿美元，半年前约 10 亿美元，明年约 100 亿美元；每代芯片算力需求约 4 倍。
  • 开源份额反转：他引用 OpenRouter 和 Vercel 网关数据，称约半年内 token 份额从“闭源七、开源三”翻成“开源七、闭源三”。
  • 租还是买：企业每年在闭源模型上花到约 1 亿美元以上，就值得转向自有的开源方案。他认为企业的大部分 token 消耗，会来自“围绕开源模型定制的系统”，而不是定制的模型。
  • 地缘：他称中国开源生态对西方开发者是净利好，但警告开源模型可能是推销整套技术栈的“特洛伊木马”，并以华为为例。
反常动作
一家美国模型公司，把“美国的开源模型”和国家安全当作核心卖点。
背后判断
推断开源模型的竞争，实质是生态与标准之争。真正赚钱的不是模型，而是围绕它的推理软件、集群管理和服务，他自己也承认单卖推理很难。
连线
推断“入场费一年涨十倍”与基辛格的“上百家芯片会收敛”是同一个逻辑：前沿训练的玩家数量也在收敛。Garman 说客户在 SageMaker 上微调开源模型（A2），开源的落地路径正在打通。
趋势
推断前沿闭源模型留给少数巨头，企业的大部分用量转向“开源模型 + 自有系统”；AI 支出出现“租转买”的拐点，私有化部署的需求会上升。
反方
依据的是第三方摘要；效率、份额等数字为自报或来自偏开发者的网关数据；Beam 的权重承诺 10 月内放出，尚未兑现（见 C 部分）。

接下来盯：Beam 权重是否按时放出、第三方评测能否复现；财富 500 强对开源模型的采用率。

S5Cisco：AI 订单两年从 23 亿涨到约 90 亿美元，“不用 AI 就丢工作”10-08

YC 播客专访 Cisco 的 Jeetu Patel。节目标题称他为 CEO，摘要称其为总裁兼首席产品官，头衔待确认。发布日期是间接核实的，以下依据 BigGo 摘要整理。

  • 订单：AI 基础设施订单第一年约 23 亿美元（指引 10 亿），第二年约 90 亿美元（指引约 50 亿）。注意这是订单，不是收入。
  • 数据中心的账：每吉瓦数据中心的造价从约 350 亿美元升到近 500 亿美元，网络占其中 10–15%。
  • 电决定选址：因为电在哪里，数据中心就建在哪里，现在要把相隔几百公里的数据中心连成一体。
  • agent 的网络胃口：他称 agent 完成同一任务所用的带宽约为人的 4.5 倍（未给出处）；重度使用 agent 的人不到 2%，他预计会升到 25%–50%。
  • 组织：Cisco 告诉约 3.2 万名工程师，不用 AI 会丢工作；起初 token 不限量，“目标不是效率”，而是先熟悉。他反而预计需要更多工程师，因为每次 AI 提效，瓶颈都会转到人身上。
  • agent 安全：Cisco 的平台覆盖非人身份、agent 清单、红队测试和运行时护栏。他举的失败案例：一个退款 agent 退了三倍货款。
反常动作
一家“老牌网络公司”的 AI 订单两年翻了四倍，又用“不用就丢工作”这样的强制手段推 AI。
背后判断
推断AI 基建的钱正从 GPU 外溢到网络、光互连和电力，与基辛格、Garman 的判断一致。“目标不是效率”则说明，在组织转型初期，熟悉度比成本更重要。
连线
推断跨数据中心互连、光互连都直接利好光模块和线缆供应链（对应 A1 第 06 点）。“agent 清单 + 非人身份”与 Garman 的限时权限、Anthropic 的越界报告构成同一张 agent 治理拼图。
趋势
推断“非人身份管理”会成为企业安全的新预算科目；AI 推行在大公司会越来越多地以“自上而下强制”的方式进行。
反方
依据的是第三方摘要；订单不等于收入；4.5 倍带宽等数字没有出处；Patel 是网络和安全产品的卖方。
