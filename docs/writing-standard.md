# 写作标准

本标准适用于「前沿雷达」各期。它以「三万」对扎克伯格 Muse 访谈的精读为样板，并汇总了历次读者反馈中确认过的规则。

## 读者
- **企业高管**：关心这件事对公司战略、组织和预算意味着什么。
- **投资人**：关心钱往哪里流，谁受益、谁承压，泡沫在哪里。
- **技术负责人**：关心架构、选型、落地风险和评测。

一律不提及任何个人读者的身份或职业。

## 样板的五个要点
1. **标题**：用「人物 + 亲口 + 读者最关心的问题」，例如「Meta 的 Muse 到底想干什么？」。副标题用一句大白话点出范式转变。
2. **小标题**：一律写成「维度：一句大白话判断」。读者只扫一遍小标题，也能拿到全篇的结论。
3. **覆盖维度**：按决策者关心的顺序展开。依次是核心定义、真实用法、用户痛点、商业模式、差异化、技术、组织、价值观、市场格局、时间表与约束，最后是启发。
4. **讲人话**：多讲故事和数字，少用行话。行话第一次出现时，用一句比喻解释。原话保留口语味。
5. **观察框要短**：每个 2–3 句，落到「对你意味着什么」。尽量给一张能直接拿来自查的清单。

## 每篇精读的结构
- **封面**：标题、副标题、两句核心原话；节目、主持、发布日期、时长、材料来源。
- **一句话总结**：用三件事概括全篇，末尾放一句最传神的原话。
- **十个要点（01–10）**：小标题写成「维度：判断」，标出时间戳，正文是要点列表或短段落。需要时加「雷达观察」。
- **深挖五步**：
  1. 反常动作
  2. 背后判断（标「推断」）
  3. 连线
  4. 趋势
  5. 反方
- **启发**：分别写给高管、投资人、技术负责人。涉及具体产业链（如线缆、连接器、PCB、光模块）时，单独加一条。涉及中国市场时，写出中国视角。
- **注**：写明发布日期、材料来源、说话人可能的利益相关。

## 今日信号的结构
1. 标题，加日期胶囊。
2. 关键事实，用要点列表。
3. 深挖五步。
4. 「接下来盯」：后续值得关注的节点。

快讯每条一行，带日期；有含义的加半句点评。

## 铁律
- **日期**：只收过去约 48 小时内发生或发布的事，每条标真实日期。旧事只能作为背景，并注明当时的日期。
- **事实**：只采用实际打开过的页面。自报、匿名、未审计或二手转述的数字必须注明。
- **推断**：一律标「推断」或「本刊推断」。
- **引语**：单句少于 15 个字或词。
- **被拒绝访问的网站**：不绕道获取，注明「原文无法访问」。

## 读者反馈中已确认的偏好
- 解读要有趋势判断，要透过现象讲出底层机制。只罗列事实是不够的。
- 一手访谈和播客的逐字稿是核心原料，要通读全文、带时间戳。
- 版式定为深海军蓝封面加橙色重点，排版紧凑。不加多余的色块、标签或卡片；被否决过的样式包括「他说 / 解读」标签和「信号 / 趋势」双栏卡。
- 篇幅不设上限。当天重要的访谈有几篇就精读几篇，信号不限条数。
- 每期三个板块：A 一手精读、B 今日信号、C 论断追踪。
